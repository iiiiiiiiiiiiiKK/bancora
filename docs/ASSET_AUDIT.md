## 6. How the index is generated

```bash
npm run assets:scan      # regenerate public/data/*.json + this report
npm run assets:validate  # fail when the index is stale or violates a data invariant
```

The script performs, in order: directory walk → UTF-8 parse → structural SVG analysis
(well-formedness, viewBox, dimensions, script/event/external references) → sha256 + path-data
signature → name resolution (README, then paired variant, then file name) → duplicate and
conflict detection → JSON + Markdown output. It is deterministic: the same assets always
produce the same index (apart from the recorded timestamp).

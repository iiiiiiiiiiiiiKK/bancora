# Bancora data schema

The Bancora asset index is generated by `scripts/scan-assets.mjs` from the SVG files in
`public/logos/` and `public/other/`. It is published at `/data/assets.json` and shipped inside
every export ZIP as `manifest.json` (a reduced projection).

Schema version: **1**

## Top-level object

```jsonc
{
  "meta": { /* Meta */ },
  "assets": [ /* Asset[] */ ],
  "issues": [ /* Issue[] */ ],
  "duplicates": { "exact": [], "visual": [] },
  "filenameConflicts": []
}
```

## `meta`

| Field | Type | Meaning |
| --- | --- | --- |
| `schemaVersion` | number | Bump when a breaking change is made to the shape. |
| `name` / `description` | string | Human-readable identification of the file. |
| `generatedAt` | string (ISO 8601) | Timestamp of the scan. Always present because the file is machine-generated. |
| `generator` | string | Path of the script that produced the file. |
| `upstream.repository` | string | `https://github.com/icongo/bank-logos` |
| `upstream.license` | string | `MIT` |
| `upstream.readme` | string | Local copy of the upstream README used for names and websites. |
| `npm.package` / `npm.version` / `npm.mapped` | string / string\|null / number | Cross-reference to `@icongo/bl`. `mapped` counts assets with a published component name. |
| `counts.total` | number | Number of indexed assets. |
| `counts.byFormat` | object | Always `{ "svg": n }` today. |
| `counts.byCollection` | object | `logos` and `other`. |
| `counts.byVariant` | object | `plain`, `rect`, `badge`. |
| `counts.documentedNames` | number | Assets whose name comes from the upstream README. |
| `counts.totalBytes` | number | Sum of file sizes. |
| `quality.pass` / `warning` / `error` | number | Structural status totals. |
| `quality.exactDuplicateGroups` | number | Groups of byte-identical files. |
| `quality.visualDuplicateGroups` | number | Groups with identical `d` path data but different bytes. |
| `quality.filenameConflicts` | number | Case-insensitive file name collisions. |
| `unknowns` | object of strings | Plain-language explanation of every field that is deliberately absent. |

## `Asset`

| Field | Type | Source | Notes |
| --- | --- | --- | --- |
| `id` | string | derived | `<collection>/<basename>`; unique and stable. |
| `name` | string | README → paired variant → file name | Never invented beyond a readable derivation. |
| `nameStatus` | `"documented"` \| `"tentative"` | derived | `tentative` means the name came from the file name. |
| `nameSource` | string | derived | Which rule produced the name. |
| `aliases` | string[] | derived | Disambiguation for paired variants (`name (badge)`). |
| `filename` | string | file system | Includes extension. |
| `relativePath` | string | file system | `logos/foo.svg`. |
| `publicPath` | string | derived | `/logos/foo.svg` — site-absolute. |
| `collection` | `"logos"` \| `"other"` | file system | Directory. |
| `variant` | `"plain"` \| `"rect"` \| `"badge"` | file name | Naming convention, not a brand classification. |
| `format` | `"svg"` | file system | |
| `fileSize` | number | file system | Bytes. |
| `sha256` | string | computed | Full-content hash. |
| `viewBox` | string \| null | SVG root | Verbatim attribute. |
| `width` / `height` | number \| null | SVG root / viewBox | For snippet sizing. |
| `country` | `null` | — | Not published upstream. Never inferred. |
| `category` | `null` | — | Not published upstream. Never inferred. |
| `website` | string \| null | upstream README | Official site as linked upstream. |
| `source.upstream` | string | constant | Repository URL. |
| `source.collection` | string | file system | |
| `source.npmExport` / `npmExports` | string \| null / string[] | `@icongo/bl` metadata | Component name(s) published upstream. |
| `source.npmPackage` | string \| null | `@icongo/bl` metadata | `@icongo/bl@1.2.0`. |
| `license.code` | string | constant | `MIT`. |
| `license.scope` | string | constant | What the licence covers. |
| `license.trademark` | `"unknown"` | constant | Never asserted. |
| `license.note` | string | constant | Trademark caveat. |
| `quality.status` | `"pass"` \| `"warning"` \| `"error"` | computed | Structural analysis. |
| `quality.findingCount` | number | computed | |
| `quality.codes` | string[] | computed | Distinct finding codes. |
| `quality.wellFormed` | boolean | computed | XML well-formedness. |
| `quality.externalRefs` | string[] | computed | Absolute `href`/`url()` targets. |

## `Issue`

Issues are only emitted for naming or structural findings:

```jsonc
{ "id": "logos/foo", "name": "…", "file": "logos/foo.svg", "kind": "naming" | "svg", "findings": [{ "code": "…", "message": "…" }] }
```

## Finding codes

| Code | Severity | Meaning |
| --- | --- | --- |
| `EMPTY_FILE` | error | Zero bytes or whitespace only. |
| `NO_SVG_ROOT` | error | Does not begin with `<svg>`. |
| `PARSE_ERROR` | error | Unbalanced or malformed markup. |
| `INVALID_VIEWBOX` | error | viewBox is not four numbers with positive size. |
| `NO_RENDERABLE_CONTENT` | error | No shape elements at all. |
| `SCRIPT_TAG` | error | `<script>` present. |
| `FOREIGN_OBJECT` | error | `<foreignObject>` present. |
| `EVENT_HANDLER` | error | `on*=` attribute present. |
| `JAVASCRIPT_URL` | error | `javascript:` URL. |
| `STYLE_IMPORT` | error | CSS `@import`. |
| `MALFORMED_ATTRIBUTE` | error | Attribute without a quoted value on the root. |
| `NO_VIEWBOX` | warning | Missing viewBox. |
| `INVALID_DIMENSION` | warning | width/height not a plain number. |
| `ASPECT_MISMATCH` | warning | Declared ratio differs from viewBox. |
| `EXTERNAL_REFERENCE` | warning | Absolute `href` or `url()`. |
| `TEXT_ELEMENT` | warning | Live `<text>` (font dependent). |
| `ENTITY_DECLARATION` | warning | XML entity declared. |
| `LARGE_FILE` | warning | Above the review threshold (400 kB). |
| `INLINE_STYLE_BLOCK` | info | `<style>` block present. |

## Guarantees enforced by `npm run assets:validate`

1. Every `id` is unique.
2. Every record points at a real, non-empty file whose size matches `fileSize`.
3. Every SVG on disk is indexed.
4. `publicPath === '/' + relativePath`.
5. `format` always matches the extension.
6. `country`, `category` stay `null`; `license.trademark` stays `unknown`.
7. `name` is non-empty and `nameStatus` is one of the two allowed values.
8. Recomputing the structural analysis reproduces the stored `quality.status`.
9. `meta.counts` agree with the records.

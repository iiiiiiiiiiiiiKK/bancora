## 4. 深色模式下 Logo 看不见 —— 已解决

原因：部分 Logo 本身是深色（黑/深灰）或纯白，直接放在同色背景上会"消失"。

方案（不改动任何原始文件）：

1. **墨色分析**：构建索引时解析每个 SVG 声明的 `fill` 颜色，计算相对亮度，归类为 `dark` / `light` / `mixed`（含 `rgb()`、`#rgb`、`#rrggbb`、命名色、style 块；未声明 fill 按 SVG 默认黑色计）。
2. **自动底板**：卡片与详情预览根据墨色自动选底板 —— 深色 Logo → 浅色底板；白色 Logo → 深色底板；彩色 Logo → 跟随主题。原始 SVG 的字节与颜色完全不变。
3. **手动覆盖**：工具条提供 自动 / 浅色 / 深色 / 网格 四档，详情面板内也可切换；选择保存在本地。
4. **透明提示**：当自动规则为了可见性反转了底板（例如深色主题下遇到深色 Logo），详情面板显示一条说明，用户知道这不是主题出错。

实测（抽样 70 张卡片，比较 Logo 像素与底板亮度）：

| 场景 | 不可见的 Logo |
| --- | --- |
| 浅色主题 + 自动 | 0 |
| 深色主题 + 自动 | 0 |
| 深色主题 + 强制深色底板（旧行为） | 2+（沧州银行、德意志银行等） |

当前索引统计：290 个深色墨、14 个浅色墨、302 个彩色。

## 16. 首页视觉重构（v4）

### 修复的真实缺陷

**12 个精选 Logo 显示不完整** —— 不是审美问题，是布局错误：

原来 12 格是**单行 Grid**（`repeat(12, 1fr)`），浏览器在 1440px 下把每格算成 107×74px；
图片用 `max-height: 100%` 在**高度不确定的网格轨道**里无法解析，于是按自身宽度撑开
到 86×86，比 74px 的格子高出 12px，父容器的 `overflow: hidden` 就把上下切掉了。
实测：**桌面 12/12 全部被裁切**，1024px 下 8/8 被裁切。

修法（结构性）：

| 项 | 原来 | 现在 |
| --- | --- | --- |
| 布局 | 单行 12 列 | **6 列 × 2 行**，≥1200px / 4 列 ≤1199px / 2 列 ≤640px |
| 图片定位 | 文档流内 + `max-height:100%`（失效） | **绝对定位 + `object-fit: contain`**，几何上不可能溢出 |
| 单元 | 只有图标，无文字 | 图标 + 银行名称（两行换行，不用省略号截断） |
| 单元尺寸 | 107×74（挤压） | 桌面 205×124，平板 230×124，手机 174×~110 |

### 首页结构重排

```
导航
├ Hero（非对称两栏 1.15 : 0.85）
│   ├ 左：eyebrow / 主标题 / 说明 / 三个按钮 / 一行数据提示
│   └ 右：5 个真实素材（1 大 + 2×2 小），细线分隔，无卡片堆叠
```

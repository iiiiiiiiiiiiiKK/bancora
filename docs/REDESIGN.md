# Bancora v2 — 界面改版与移动端说明

本次改版针对四项反馈：整体视觉、作者 X 入口、iPhone / 移动端自适应、深色模式下 Logo 不可见，以及界面中文化。

## 1. 视觉体系（v2）

| 项 | v1 | v2 |
| --- | --- | --- |
| 背景 | 暖米色 `#f6f4ef` | 冷灰纸面 `#f1f3f5` |
| 主色 | 海军蓝 + 青绿 | 深墨 `#0b1a26` + 深青 `#0c6b5b` |
| 标题字体 | 系统无衬线 | 衬线展示体（Iowan / Palatino / Songti），只用于大标题 |
| 卡片 | 无内框、预览直接贴边 | 预览区内嵌底板 + 边框，信息区更紧凑 |
| 组件 | 圆角偏大、阴影偏重 | 4–13px 小圆角、一层描边、极轻阴影 |
| 深色 | 中性黑 | 冷调深色，全套 token 同步（背景/文字/边框/输入/弹窗/代码块/预览底板） |

设计原则：让银行 Logo 本身成为页面上最亮的元素；界面只用一条强调色、有限的层级和大量留白。

## 4. 深色模式下 Logo 看不见 —— 已解决

原因：部分 Logo 本身是深色（黑/深灰）或纯白，直接放在同色背景上会"消失"。

方案（不改动任何原始文件）：

1. **墨色分析**：构建索引时解析每个 SVG 声明的 `fill` 颜色，计算相对亮度，归类为 `dark` / `light` / `mixed`（含 `rgb()`、`#rgb`、`#rrggbb`、命名色、style 块；未声明 fill 按 SVG 默认黑色计）。
2. **自动底板**：卡片与详情预览根据墨色自动选底板 —— 深色 Logo → 浅色底板；白色 Logo → 深色底板；彩色 Logo → 跟随主题。原始 SVG 的字节与颜色完全不变。
3. **手动覆盖**：工具条提供 自动 / 浅色 / 深色 / 网格 四档，详情面板内也可切换；选择保存在本地。
4. **透明提示**：当自动规则为了可见性反转了底板（例如深色主题下遇到深色 Logo），详情面板显示一条说明，用户知道这不是主题出错。

实测（抽样 70 张卡片，比较 Logo 像素与底板亮度）：

| 场景 | 不可见的 Logo |
| --- | --- |
| 浅色主题 + 自动 | 0 |
| 深色主题 + 自动 | 0 |
| 深色主题 + 强制深色底板（旧行为） | 2+（沧州银行、德意志银行等） |

当前索引统计：290 个深色墨、14 个浅色墨、302 个彩色。

## 5. 中文化

- 界面默认中文（`zh-CN`），标题、导航、按钮、筛选、详情、导出、转换器、检查器、页脚、404 全部中文。
- 顶部 `EN / 中` 按钮一键切换英文，偏好保存在 `localStorage`，刷新后保持；`<html lang>` 同步更新。
- 页面 `<title>`、`meta description`、OG 文案、`noscript` 均已本地化。
- 银行名称等数据本身保持上游原文，不做翻译。

## 10. 工具条控件高度统一

问题：排序下拉、预览底板分段控件、"标准/只看收藏"胶囊按钮高度不一致（32 / 36 / 30 px），视觉上参差。

修复：

- 新增设计 token `--control-h`（桌面 34px，手机 36px），所有紧凑控件统一引用；
- 排序下拉、`.segment` 组、`.chip--button`、`.btn--sm` 全部改用同一高度；
- 分段控件重构为「一组相连的分段按钮」：无内边距、段与段之间 1px 分隔、选中段用浅青底 + 内阴影下划线，整组与旁边控件严格同高同基线；
- 详情面板的底板切换与收藏/导出篮按钮、检查器的状态筛选也同时对齐。

验证：桌面 4 个控件全部 34px、`top` 完全一致；手机上全部 36px。新增回归测试「toolbar controls share one height and baseline」。浏览器检查 31 → **32**。


## 11. Hero 统计与页脚平衡

### 统计条（606 / 606 / 3 / 422）

原本是「数字在上、标签在下」的四宫格，数字大小一致但读起来像四个孤立的数。改为三段式表格式排版：

```
已收录 Logo        已收录 SVG 文件        输出格式          有官方名称
606                606                   3                 422
全部素材            全部可下载             SVG · PNG · WebP   来自上游文档
```

- 第一行小号大写标签，第二行衬线数字（tabular-nums 对齐），第三行等宽小字说明
- 四列等宽、四行严格同基线，桌面 165×83，手机两列 178×74
- 用 `<dl>/<dt>/<dd>` 语义标签，读屏软件能正确关联标签与数值
- 深色模式同样对齐，无截断

### 页脚右侧空白

原来品牌块占左侧 758px，右侧只有 506px 的三列链接，中间和底部大片留白。重新分配为两列 + 两行：

```
┌─────────────────────────────┬──────────────────────────────┐
│ Bancora + 简介               │  工具      开发      项目     │
│                             │  素材库    开发者    关于     │
├─────────────────────────────┤  …         …        …        │
│ 606 SVG │ MIT │ 100% 本地    │                              │
└─────────────────────────────┴──────────────────────────────┘
```

- 左侧：品牌 + 简介 + 一条三格的小数据条（606 SVG / MIT / 100% 本地处理）
- 右侧：三列站点地图垂直居中，填满右侧空间
- 页脚总高从 301px 降到 **210px**，视觉上左右平衡
- ≤1120px 收为单列：品牌 → 数据条 → 胶囊链接，手机高度 292px


## 12. 顶栏图标按钮尺寸统一

问题：收藏 / 𝕏 / 语言 / GitHub / 主题 / 汉堡菜单之间差 1–4px：

| 位置 | 原因 |
| --- | --- |
| `.icon-btn` 用 34×34 | 基础尺寸 |
| `.x-link` 单独写了字体大小 | 字形基线不同，视觉上略大 |
| ≤640px 覆盖为 40×40 | 只改了 `.icon-btn`，𝕏 是同一类但字号不同 |
| ≤380px 覆盖为 `36×38` | **宽高不相等**，直接不是正方形 |

修复：新增 `--header-btn` token，桌面 36px、≤640px 40px、≤380px 34px，宽高共用同一个值；
`.x-link` 不再单独定义尺寸，只调整字形视觉重量；所有按钮 `padding: 0`、`flex: none`。

验证：1440 / 1024 / 768 / 430 / 390 / 375 / 320 七种宽度下，顶栏所有可见按钮均为**同一个正方形尺寸**且顶部基线一致；新增回归测试「every header icon button is the same square size」。浏览器检查 33 → **34**。

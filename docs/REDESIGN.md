# Bancora v2 — 界面改版与移动端说明

本次改版针对四项反馈：整体视觉、作者 X 入口、iPhone / 移动端自适应、深色模式下 Logo 不可见，以及界面中文化。

## 1. 视觉体系（v2）

| 项 | v1 | v2 |
| --- | --- | --- |
| 背景 | 暖米色 `#f6f4ef` | 冷灰纸面 `#f1f3f5` |
| 主色 | 海军蓝 + 青绿 | 深墨 `#0b1a26` + 深青 `#0c6b5b` |
| 标题字体 | 系统无衬线 | 衬线展示体（Iowan / Palatino / Songti），只用于大标题 |
| 卡片 | 无内框、预览直接贴边 | 预览区内嵌底板 + 边框，信息区更紧凑 |
| 组件 | 圆角偏大、阴影偏重 | 4–13px 小圆角、一层描边、极轻阴影 |
| 深色 | 中性黑 | 冷调深色，全套 token 同步（背景/文字/边框/输入/弹窗/代码块/预览底板） |

设计原则：让银行 Logo 本身成为页面上最亮的元素；界面只用一条强调色、有限的层级和大量留白。

## 4. 深色模式下 Logo 看不见 —— 已解决

原因：部分 Logo 本身是深色（黑/深灰）或纯白，直接放在同色背景上会"消失"。

方案（不改动任何原始文件）：

1. **墨色分析**：构建索引时解析每个 SVG 声明的 `fill` 颜色，计算相对亮度，归类为 `dark` / `light` / `mixed`（含 `rgb()`、`#rgb`、`#rrggbb`、命名色、style 块；未声明 fill 按 SVG 默认黑色计）。
2. **自动底板**：卡片与详情预览根据墨色自动选底板 —— 深色 Logo → 浅色底板；白色 Logo → 深色底板；彩色 Logo → 跟随主题。原始 SVG 的字节与颜色完全不变。
3. **手动覆盖**：工具条提供 自动 / 浅色 / 深色 / 网格 四档，详情面板内也可切换；选择保存在本地。
4. **透明提示**：当自动规则为了可见性反转了底板（例如深色主题下遇到深色 Logo），详情面板显示一条说明，用户知道这不是主题出错。

实测（抽样 70 张卡片，比较 Logo 像素与底板亮度）：

| 场景 | 不可见的 Logo |
| --- | --- |
| 浅色主题 + 自动 | 0 |
| 深色主题 + 自动 | 0 |
| 深色主题 + 强制深色底板（旧行为） | 2+（沧州银行、德意志银行等） |

当前索引统计：290 个深色墨、14 个浅色墨、302 个彩色。

## 5. 中文化

- 界面默认中文（`zh-CN`），标题、导航、按钮、筛选、详情、导出、转换器、检查器、页脚、404 全部中文。
- 顶部 `EN / 中` 按钮一键切换英文，偏好保存在 `localStorage`，刷新后保持；`<html lang>` 同步更新。
- 页面 `<title>`、`meta description`、OG 文案、`noscript` 均已本地化。
- 银行名称等数据本身保持上游原文，不做翻译。
